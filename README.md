# Natural Language Linear Programming Solver

In this project, you can convert any Natural Language optimisation problem into a tangible solution and see the charted solution

-> Enter a linear programming optimisation problem using English.
-> The Google Gemini API converts the problem into a format containing the objective function, variables and constraints.
-> Pydantic validates the generated output.
-> The validated model is then solved by PuLP.
-> Logging to record failiures
